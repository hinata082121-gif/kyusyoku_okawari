# 録画専用モードガイド

「給食おかわり争奪戦」をTikTok、YouTube Shorts、Instagram Reels向けに録画するための運用メモです。

## 録画用URL

勝利:

https://kyusyoku-okawari.vercel.app/?recording=win

敗北:

https://kyusyoku-okawari.vercel.app/?recording=lose

ランダム:

https://kyusyoku-okawari.vercel.app/?recording=random

コレクション:

https://kyusyoku-okawari.vercel.app/?recording=collection

サムネイル:

https://kyusyoku-okawari.vercel.app/?recording=thumbnail

通常プレイ:

https://kyusyoku-okawari.vercel.app/

## 推奨録画手順

1. 録画したいURLを開く
2. 画面が縦長に収まっていることを確認する
3. 録画を開始する
4. 1周分を録画する
5. 冒頭の余白と最後の暗転を必要に応じてカットする
6. 15〜25秒に収める
7. BGMはTikTok / Shorts / Reels側の流行音源を使う

録画モードは自動進行です。通常の `game_start` や `result_view` ではなく、GA4には `promo_view` / `promo_variant` のみを送信します。

## スマホ録画手順

1. スマホで録画用URLを開く
2. ブラウザを縦画面のまま表示する
3. iPhoneはコントロールセンター、Androidは画面録画機能から録画する
4. 20秒前後録画する
5. CapCutなどで冒頭と末尾を整える

ブラウザのアドレスバーが映り込む場合は、ページを一度スクロールするか、ブラウザの全画面表示に近い状態で録画してください。

## OBS録画手順

1. ブラウザで録画用URLを開く
2. OBSでブラウザウィンドウまたは画面キャプチャを追加する
3. キャンバスを1080 x 1920に設定する
4. ゲーム画面を中央に拡大配置する
5. 20秒前後録画する
6. 必要ならCapCutで9:16のまま書き出す

## 推奨動画尺

- 勝利: 20秒前後
- 敗北: 20秒前後
- コレクション訴求: 20〜25秒
- サムネイル: 静止画スクショ用

## ショート動画向け構成

- 冒頭2秒で結果やレアメニューを見せる
- 中盤で「早押し」「じゃんけん」「レア度」を伝える
- 終盤でリザルトまたはコレクション登録を見せる
- 最後に「今すぐブラウザで遊ぶ」を1.5〜2秒残す

## CapCutでの最低限の編集手順

- 冒頭の録画開始余白をカット
- 15〜25秒に収める
- BGMは投稿先の流行音源を使う
- ゲーム内テロップが読めるように、外部テロップは足しすぎない
- 最後のCTAを1.5〜2秒残す
- 必要なら画面上部に「無料ブラウザゲーム」などの短い補足だけを追加する
